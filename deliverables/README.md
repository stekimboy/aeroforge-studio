## The design that was actually printed and flown: `My-Backtest.step`

`My-Backtest.step` (22.4 MB, Open CASCADE STEP from Fusion) is the user's
FINAL design as built - the one that was 3D-printed and test-flown in real
life. It is the AeroForge output after the user's own post-generation edits
in Autodesk Fusion (below). Treat it as ground truth for "what a flown
AeroForge wing looks like"; nothing in the code generates the additions.

## Post-generation wing joiners (manual, in Fusion - NOT generated by the app)

`wing-joiner-pegs-fusion.png` is a Fusion screenshot of that design's
`wing_left` / `wing_right` panels, cropped to the viewport (the original
full-desktop capture is not in the repo). The
user added, by hand after generation:

- **two cylindrical joiner pegs per wing panel, protruding from the root
  (inboard) face** into the centre body, each **14 mm diameter x 40 mm
  long, plus printing tolerances**;
- **matching holes in the centre body** (fuselage) so the wing panels
  locate on the pegs and are **glued** in place.

This is a build-and-assembly detail the user applies themselves; it is
deliberately not part of the generator (no code change requested). If a
future version wants to generate it, the spec above is the one to match:
Ø14 x 40 mm pegs on the wing root face, clearance holes in the centre body,
glued joint.
